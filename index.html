Not authenticated

Atlantic Waves uses Deriv OAuth 2.0 so your Deriv password is never entered into this app. The server exchanges the authorization code and obtains the authenticated trading WebSocket URL.

Live Trading Guide

  1. Register an OAuth application in Deriv’s developer dashboard.
  2. Set its redirect URL to your deployed /oauth/callback.
  3. Put the client ID and redirect URL in the server environment.
  4. Open Atlantic Waves and connect your Deriv account.
  5. Select the intended real account.
  6. Open the trading connection and verify the balance.
  7. Only then arm real trading.
Never send your Deriv password, PAT, OAuth client secret, or access token to anyone in chat. Keep credentials on the server.
