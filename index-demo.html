Guide

How Atlantic Waves works

The planned live engine reads Deriv ticks, extracts last digits, evaluates rolling patterns and only considers a Digit Differs contract when the signal and payout pass the risk gate.

The downloadable build is a mobile-ready demo shell with a local trade simulator. It is not a promise of profit and it does not contain your Deriv credentials.

Before live trading

  1. Create/authorize a Deriv app using OAuth 2.0 or a secure token flow.
  2. Run the strategy on Demo for extensive testing.
  3. Backtest the signal rules on tick history.
  4. Keep hard stake, loss-streak and daily-loss limits.
